OVERVIEW

금융 대출상품 추천 AI Agent

광주은행 대출 상품 공시 정보를 검색해 사용자의 재무 상황에 맞는 상품을 추천하고, 예상 상환액까지 계산해주는 RAG 기반 AI Agent입니다. 은행 업무 특성상 고객 재무 정보를 외부로 보낼 수 없다는 제약을 반영해, AI 모델(채팅·임베딩)을 전부 로컬 환경에서 구동하는 구조로 직접 전환해 설계·구현했습니다.

APR_01

AI 생성과 결정론적 계산 분리

상환액·DSR 같은 숫자는 AI가 아니라 별도의 결정론적 계산 로직으로 산출하고, AI는 그 결과를 자연어로 설명하는 역할만 맡습니다. AI가 금액을 잘못 계산하거나 지어내는 걸 구조적으로 차단하기 위한 설계입니다.

APR_02

온프레미스 전환

은행은 고객 재무 정보를 외부 클라우드 AI로 보내기 어렵다는 점을 반영해, 채팅·임베딩 모델을 전부 로컬(Ollama)로 구동하도록 구조를 전환했습니다.

RES_01

사실 정보 원문 표시 검증

상품명·한도·금리 같은 사실 정보는 항상 크롤링 원문 그대로 표시하도록 구조화 추출 단계에서 검증해, AI가 수치를 임의로 바꾸는 사례가 없도록 했습니다.

RES_02

검색 도구 단위 테스트

AI Agent가 쓰는 검색 도구(search_loan_products)에 단위 테스트를 작성해 결과가 항상 올바른 형식으로 반환되는지 확인했습니다. 사람 라벨링 기반의 정량적 검색 품질 평가(Precision@k, Hit Rate, MRR)는 ETF 프로젝트에서 먼저 도입했고, 이 프로젝트에도 적용할 계획입니다.

KEY FEATURES

주요 기능

FEAT_01

AI 상담 추천

재무 상황(소득·신용점수·대출 목적 등)을 자연어로 입력하면, 조건에 맞는 대출 상품을 추천 이유·한도·금리·출처 링크와 함께 카드 형태로 보여줍니다.

FEAT_02

상환액 계산기 연동

추천받은 상품을 그대로 상환 계산기로 넘겨, 원금·금리·기간·상환방식을 입력하면 월 상환액과 총 이자를 즉시 계산합니다.

FEAT_03

DSR 계산 & 조건 비교

연소득을 추가로 입력하면 DSR까지 함께 계산되고, '다른 상환 기간과 비교하기'로 서로 다른 조건의 월 상환액·총 이자를 나란히 비교할 수 있습니다.

IMPROVEMENTS

개선할 점

IMP_01

검색 품질 정량 평가 도입

ETF 프로젝트에서 쓴 사람 라벨링 기반 평가(Precision@k, Hit Rate, MRR)를 이 프로젝트에도 적용해, 대출 상품 검색 품질을 수치로 검증할 계획입니다.

IMP_02

실제 심사 데이터 반영

현재는 공개된 상품 정보만 사용하는데, 실제 신용 심사 데이터와 연동하면 더 정확한 승인 가능성까지 안내할 수 있을 것 같습니다.
